# 🛒 AI E-Commerce Analytics Assistant

An AI-powered **E-Commerce Analytics Assistant** that combines **Data Analytics and Generative AI** to analyze E-Commerce sales data and generate meaningful business insights.

The project uses **Python, Pandas, Matplotlib, and Groq AI** to process data, calculate important business metrics, create visualizations, identify trends, and provide AI-generated insights.

---

## 🎯 Project Objective

The objective of this project is to demonstrate how **Generative AI can be combined with traditional data analytics** to make E-Commerce data easier to understand and analyze.

Instead of manually analyzing large datasets, the assistant processes the data and provides useful business insights through automated analytics and AI.

---

## 📊 Analytics

The project can analyze available business metrics such as:

* Total Sales
* Total Profit
* Total Quantity
* Average Sales
* Product Performance
* Category Performance
* Sales Trends
* Profit Trends
* Other available metrics depending on the dataset

---

## 🤖 Generative AI

The project integrates **Groq AI** to provide an intelligent analysis layer.

After processing the dataset, the AI can generate insights about:

* Sales performance
* Product performance
* Business trends
* Profitability
* Important patterns in the data
* Potential areas that require attention

## ▶️ How to Run

1. Open the project notebook in **Google Colab**.
2. Install the required Python libraries.
3. Add your **Groq API Key** securely.
4. Upload your E-Commerce dataset.
5. Run the notebook cells.
6. Review the calculated KPIs and visualizations.
7. View the AI-generated business insights.
